# FTags

**Цветные маркеры разной формы и быстрый поиск Spotlight для документов, папок и компендиумов Foundry VTT (только для GM)**

Упорядочивайте сущности мира и компендиумы прямо в стандартных каталогах Foundry без лишнего текста и изменения шрифта — работает в любой системе без зависимостей, плюс автоматические фасеты поиска для D&D 5e.

## Установка

Вставьте **URL манифеста** в окно установки модулей Foundry VTT (**Дополнительные модули → Установить модуль → Manifest URL**):

```text
https://github.com/TacticalOtaku/FTags/releases/latest/download/module.json
```

**Требования:** Foundry VTT **14** (проверено на `14.367`), любая игровая система, ноль внешних зависимостей.  
**Ручная установка:** скачайте `ftags-v<версия>.zip` со страницы [GitHub Releases](https://github.com/TacticalOtaku/FTags/releases/latest), распакуйте в `{Foundry user data}/Data/modules/ftags` (чтобы `module.json` лежал внутри `ftags`) и включите **FTags** в настройках мира.

> [!NOTE]
> Вся функциональность доступна только гейм-мастеру (`game.user.isGM`): игроки не видят кнопок, точек, диалогов и пунктов контекстного меню.

## Возможности

- **Поддерживаемые сущности:** `Actor`, `Item`, `Scene`, `JournalEntry`, `RollTable`, `Cards`, `Playlist`, `Macro`, мировые папки, а также документы и папки разблокированных компендиумов.
- **Минималистичные маркеры (6 px):** рядом с названием строки выводятся до **3** значков выбранной формы (`●` круг, `■` квадрат, `◆` ромб, `★` звезда, `▲` треугольник) и единая многоцветная полоса переполнения при большем числе меток. Модуль не меняет шрифт и плотность списков Foundry.
- **Мгновенная фильтрация со строки:** наведите на маркеры, чтобы увидеть все назначенные метки; клик по отдельному значку открывает **Spotlight**, сразу отфильтрованный по этой метке. Модуль никогда не скрывает строки каталога.
- **Палитра Spotlight (`Ctrl+Shift+F`):** поиск по документам мира и компендиумам по названию или метке (до 100 результатов) с полной навигацией клавиатурой (`↑` `↓` `Enter` `Esc`) и контрастными чипами меток.
- **Гибкие фильтры для каждого GM:** включение и исключение меток с режимом `ANY` / `ALL`, фильтрация по типу документа, сортировка по релевантности/имени/типу и отдельное сохранение настроек на пользователя.
- **Автоматические метки D&D 5e:** вычисляемые фасеты для типа существа, CR/ПО (`0–30`, `1/8`, `1/4`, `1/2`), типа предмета, редкости и категории оружия (ближнее/дальнобойное) с двуязычными алиасами (EN/RU). Скрыты от точек в каталоге, окна назначения и чипов результатов.
- **Безопасное наследование папок и удаление:** метки папок не наследуются будущими документами автоматически; при желании можно разово применить метки ко всему текущему содержимому дерева папок (включая компендиумы), а заблокированные компендиумы защищены от случайной записи. Удаление метки атомарно очищает мир и разблокированные компендиумы — при ошибке чтения или записи удаление из словаря отменяется.
- **Готовые наборы и перенос словаря:** три набора меток без дублирования (**«Подготовка»**, **«Сюжет»**, **«Отношения»**) и экспорт/импорт JSON по схеме v2 с предпросмотром изменений (словари устаревшей схемы v1 импортируются с круглой формой по умолчанию).

## Использование

1. **Создание меток и пресетов:** откройте _Настройки игры → Настройки модулей → FTags → Управление метками → Открыть менеджер меток_ (или кнопку с ярлыком в панели каталога). Задавайте метки до 48 символов (`500` на мир), выбирайте hex-цвет и форму (`●` `■` `◆` `★` `▲`) или используйте **Готовые наборы меток**.
2. **Назначение меток:** нажмите ПКМ по документу или папке (включая окна компендиумов) → **Управление метками**.
3. **Применение к содержимому папки (опционально):** при назначении метки папке отметьте **«Также добавить выбранные метки текущему содержимому папки»**, чтобы разово промаркировать вложенные документы (новые объекты в папке останутся без меток).
4. **Поиск через Spotlight:** нажмите `Ctrl+Shift+F` (настраивается в _Настройки управления → FTags → Открыть FTags Spotlight_), кнопку-лупу в панели каталога или кликните по любой цветной точке в списке.

> [!TIP]
> Повторное применение готового набора не создаёт дубликатов и не перезаписывает вручную изменённые цвета и формы. Если компендиум заблокирован, кнопка сохранения отключается с понятным предупреждением.

## Поиск Spotlight и синтаксис запросов

В системе **D&D 5e** автоматически вычисляются фасеты свойств документов без записи во флаги; русские и английские алиасы работают независимо от языка интерфейса.

| Запрос                                                        | Что найдёт                                                                                         |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `goblin camp`                                                 | Объекты, имя или метки которых содержат и `goblin`, и `camp`                                       |
| `волк #подготовить`                                           | Объекты со словом «волк» в имени и меткой, совпадающей с «подготовить» (`#` ищет только по меткам) |
| `#"очень редкий"`                                             | Поиск по многословной метке в кавычках                                                             |
| `нежить CR 3` / `undead cr:3`                                 | Нежить с точным CR `3`                                                                             |
| `оружие необычной редкости ближнее` / `weapon uncommon melee` | Оружие необычной редкости ближнего боя                                                             |
| `CR >= 5` / `CR 1/8` / `ПО 1/2`                               | Точные сравнения по CR (`=`, `<`, `>`, `<=`, `>=`) с объединением через `AND`                      |

Нажмите кнопку ползунков в Spotlight для расширенных фильтров (ручные метки + раскрываемый блок **Автоматические метки · D&D 5e**, режим `ANY`/`ALL`, фильтр по типам документов, сортировка и **Сброс**). Несвязанные обновления документов (например, изменение хитов) не вызывают пересборку индекса.

## API и хранение данных

### Публичный API для макросов и модулей

Объект `game.modules.get("ftags").api` заморожен (`Object.freeze`); все методы проверяют `game.user.isGM` и возвращают `[]` / `null` для игроков:

| Метод                        | Назначение                                                                  |
| ---------------------------- | --------------------------------------------------------------------------- |
| `openTagManager(parentApp?)` | Открывает окно менеджера меток                                              |
| `openSpotlight(options?)`    | Открывает Spotlight (`options.includeTagId` сразу добавляет метку в фильтр) |
| `listTags()`                 | Возвращает текущие определения ручных меток из словаря мира                 |
| `getAssignments(document)`   | Возвращает очищенный список ID ручных меток на документе                    |

### Хранение и ограничения

| Данные                                                   | Хранилище                          | Область                 |
| -------------------------------------------------------- | ---------------------------------- | ----------------------- |
| Словарь меток (схема v2: `id`, `name`, `color`, `shape`) | Настройка `ftags.tagDictionary`    | Мир (общий для всех GM) |
| Фильтры Spotlight                                        | Настройка `ftags.spotlightFilters` | Индивидуально на GM     |
| Назначения на документах и папках                        | Флаг `flags.ftags.tagIds`          | Документ / папка        |
| Отладочное логирование                                   | Настройка `ftags.debug`            | Клиент                  |

> [!CAUTION]
> Данные мировых настроек технически передаются клиентам игроков по сети Foundry, даже если UI модуля скрыт от игроков. Не храните сюжетные спойлеры в названиях меток.

- **Экспорт / импорт:** экспорт сохраняет определения меток (без назначений и `auto-dnd5e-`-фасетов); импорт поддерживает схемы v1 и v2, показывает предпросмотр и отклоняет конфликтующие имена и некорректные файлы.
- **Ограничения:** нет интерфейса для игроков; работает на уровне `JournalEntry` (без `JournalEntryPage`); ищет по названиям и меткам (без полнотекстового поиска по телу заметок); при одновременной правке словаря двумя GM действует принцип последней записи.

## Разработка

Требуется **Node.js ≥ 24** (`npm ci`). GitHub Actions проверяет изменения в [ci.yml](.github/workflows/ci.yml) и публикует релизы по тегам `v*` через [release.yml](.github/workflows/release.yml).

```bash
npm ci           # Установка dev-инструментов (ESLint, Prettier, Handlebars)
npm run check    # ESLint + проверка шаблонов/локалей + тесты node --test
npm run deploy   # Копирование модуля в локальную папку Foundry Data/modules/ftags
npm run package  # Проверка module.json и сборка dist/ftags-v<версия>.zip
npm run release  # Запуск npm run check + сборка архива
```

Дополнительный стенд Playwright (`tools/ui-harness.html`): `node tools/check-ui.mjs`.
